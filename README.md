**Micro Fluid Dispenser**
An embedded precision fluid dispensing system developed during an internship at Aspier Instruments, Chennai. The system uses a low-power microcontroller to control motor-driven fluid dispensing with real-time status monitoring and wireless communication.

**Features**
Precise and repeatable fluid dispensing
Embedded C-based firmware
Motor control using DRV8837C
Bidirectional DC gear motor operation
Switch-based input and safety control
3-color LED status indication
EEPROM data storage
Serial communication
BLE-based control and monitoring

**Hardware**
MCU: ATTiny414-SS
Motor Driver: DRV8837C
Motor: Micro 300 Series DC Gear Motor
BLE: DA14531MOD BLE 5.1
Inputs: Micro switches and slide switches
Indicator: 3-color LED

**Software**
Embedded C
Arduino IDE
Serial Communication
EEPROM
BLE 

**Applications**
Industrial fluid automation
Laboratory micro-dispensing
Biomedical fluid delivery
Sensor-actuator embedded systems

**Project Outcome**
The project provided practical experience in embedded firmware development, motor control, hardware interfacing, debugging, precision timing, wireless communication, and industrial automation.
